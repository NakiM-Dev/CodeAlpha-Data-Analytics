TASKS 1–3 SUBMISSION PACKAGE

Project:
Web Scraping, Exploratory Data Analysis (EDA) and Data Visualization

Source:
Books to Scrape — https://books.toscrape.com/

Files:
1. Tasks_1_3_Submission_Report.docx
   Submission-ready report covering Tasks 1–3.

2. Tasks_1_3_Analysis.ipynb
   Jupyter Notebook containing the workflow and code.

3. data/books_scraped_sample.csv
   20-record sample captured from catalogue page 1.

4. code/task1_web_scraping.py
   BeautifulSoup scraper. Configured for all 50 catalogue pages.

5. code/task2_eda.py
   EDA code covering structure, missing values, descriptive statistics, hypothesis check and IQR anomaly detection.

6. code/task3_visualization.py
   Matplotlib visualization code.

7. visualizations/
   Four PNG charts used in the report.

IMPORTANT:
The source is a scraping-practice website. Its prices and ratings are randomly assigned and should not be interpreted as real market data.
The supplied scraper can collect the complete 1,000-book catalogue when run with internet access.
